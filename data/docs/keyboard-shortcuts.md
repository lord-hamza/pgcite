# Keyboard shortcuts

Shortcuts work in the desktop apps and in the browser. On macOS use Cmd, and on Windows and Linux use Ctrl wherever this page says Cmd. Press Cmd+/ at any time to see every shortcut, including the ones you customized.

## Navigation

- Cmd+K opens quick search, where you can jump to any page, task or space by name.
- Cmd+Shift+F searches inside the current space.
- Cmd+[ and Cmd+] go back and forward in your history.
- Cmd+Shift+B shows or hides the sidebar.

## Creating content

- Cmd+N creates a new page in the current space.
- Cmd+Shift+T creates a new task. Browsers reserve this shortcut, so use Alt+Shift+T in the web app instead.
- Cmd+Shift+M adds a comment to the selected text.
- Cmd+Enter marks the selected task as complete.

## Quick capture

Quick capture lets you write a note or task without switching to the Fernhill window. The global shortcut is Cmd+Shift+Space on macOS and Ctrl+Alt+Space on Windows and Linux. It works whenever the desktop app is running, even in the background. Notes go to your Inbox page unless you choose a space before saving.

## Formatting while you type

- Type `/` to open the block menu.
- Type `#`, `##` or `###` followed by a space to start a heading.
- Type `[]` followed by a space to start a checkbox.
- Type `>` followed by a space to start a quote.
- Type `---` on an empty line to add a divider.
- Cmd+B, Cmd+I and Cmd+U toggle bold, italic and underline.

## Customizing shortcuts

In the desktop app, open Settings > Keyboard to change any shortcut, including the quick capture shortcut. Custom shortcuts are saved in `~/.fernhill/keybindings.json`, so you can copy the file to another computer. Shortcut customization is not available in the browser.
